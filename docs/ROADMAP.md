# 静读产品与工程路线图

本文档是项目唯一的总体计划与进度基准。README 用于介绍当前能力，MIGRATION.md 用于记录架构迁移细节；阶段是否完成，以本文档的验收标准和真实 Edge 体验为准。

## 状态定义

- ✅ 已完成：功能、自动化测试和真实 Edge 验收均通过，且没有已知阻断问题。
- 🟡 进行中：主要能力已实现，但仍有缺陷、兼容性问题或验收项未通过。
- ⬜ 未开始：尚未进入实现。
- ⏸ 暂缓：不属于当前版本目标。

提交代码、单元测试通过或自动化测试通过，不等于阶段完成。涉及浏览器存储、扩展安装、文件兼容和阅读交互的阶段，必须使用实际安装方式和真实文件验收。

## 当前基线与总体进度

- 当前稳定使用方式：在 Edge 中加载 D:\projects\reading-plugin 项目根目录。
- 当前稳定运行主体：原生 HTML、CSS 和 JavaScript 阅读器。
- WXT 构建目录 .output/chrome-mv3：已有构建和测试，但用户实际体验存在 bug，暂不作为稳定版本。
- 当前分支：agent/reader-v0.2.0。
- 当前版本：0.2.0。

## 阶段 0：稳定基线与数据安全

状态：🟡 进行中，90%。这是当前最高优先级。

已完成：

- ✅ 书籍 Blob、元数据、阅读进度和批注保存在 quiet-reader IndexedDB 的 books 仓库中。
- ✅ 设置保存在扩展 localStorage 中。
- ✅ Manifest 已加入固定公钥，后续新安装不会因项目路径变化再次改变扩展 ID。
- ✅ 当前可用根目录版本被确认为迁移期间的稳定基线。

- ✅ 已增加版本化书库备份，包含书籍、进度、高亮、批注和非敏感设置。
- ✅ 已增加合并恢复、格式版本校验、SHA-256 完整性校验和重复记录检测。
- ✅ 数据库升级到 schema v2，并以迁移注册表管理逐版本升级。
- ✅ v1→v2 在单个 IndexedDB versionchange 事务中完成；异常会 abort 并原子保留旧库。
- ✅ 备份记录数据库 schema，兼容旧备份并拒绝导入未来 schema 数据。

待完成：
- ⬜ 从根目录版迁移到 WXT 版前提供显式迁移与恢复路径。
- ⬜ 覆盖移动目录、重新加载、升级、卸载重装等真实 Edge 场景。

验收标准：

- 备份后清空测试环境，能够恢复书库和全部阅读状态。
- 相同版本重新构建、移动输出目录和升级版本均不丢数据。
- 数据迁移失败时保留旧数据，并向用户提供可理解的恢复提示。

## 阶段 1：多格式阅读核心

状态：🟡 进行中，85%。

已完成：

- ✅ PDF 基于 PDF.js 打开本地文件、按需渲染、显示文本层。
- ✅ EPUB 基于 Foliate.js 打开正文、目录、封面和元数据。
- ✅ MOBI、AZW3 基于 Foliate.js 打开正文和目录。
- ✅ 支持格式检测、书架保存和重新打开。
- ✅ 对 Foliate 的 XHTML 正文、语言标签和 sandbox 问题加入兼容修复。

待完成：

- ⬜ 建立更广泛的真实书籍兼容样本，包括中文、英文、图文混排、超长章节和异常目录。
- ⬜ 对损坏文件、加密文件和不支持格式提供明确错误说明。
- ⬜ 验证大文件的内存占用、加载速度和崩溃恢复。

验收标准：

- 每种支持格式至少使用 5 本不同来源的真实书籍通过打开、目录、导航和恢复测试。
- 错误文件不会导致空白页或无限加载。

## 阶段 2：阅读体验

状态：🟡 进行中，75%。

已完成：

- ✅ 主题、字体、字号、行高和页面宽度设置。
- ✅ 顶部栏收缩与基础阅读工具栏。
- ✅ EPUB、MOBI、AZW3 分页和滚动模式。
- ✅ 滚动模式支持连续章节文档流，章节结尾可与下一章开头同时出现。
- ✅ PDF 缩放、页码跳转、目录和进度恢复。

待完成：

- ⬜ 继续验证滚轮在短章节、空白尾页、图片章节和超长章节中的行为。
- ⬜ 优化连续滚动的预加载、内存回收和滚动位置稳定性。
- ⬜ 统一根目录版与 WXT 版的交互、样式和快捷键。
- ⬜ 完善无障碍、触控板、键盘和高分屏体验。

验收标准：

- 阅读过程中不出现突兀翻页、空白正文、滚轮失效和章节位置跳动。
- 刷新或关闭浏览器后能够回到接近原位置。

- ✅ 搜索结果跳转和基础批注列表。

验收标准：

- 重启、改变排版和升级版本后，高亮仍能准确定位。
- 搜索和批注可以导出，并能在干净环境中恢复。

## 阶段 4：AI 阅读助手

状态：🟡 进行中，50%。

已完成：

- ✅ 划词操作：解释、翻译、简化表达、分析术语、补充背景。
- ✅ 章节助手：摘要、核心观点、人物和事件、时间线、重要概念。
- ✅ 支持 OpenAI 兼容接口、流式响应和停止生成。
- ✅ 只有用户主动触发时才发送选中文字或章节上下文。

待完成：

- ⬜ 使用真实 API 完成错误、超时、限流、取消和权限验收。
- ⬜ 增加模型配置检测、用量提示和敏感信息说明。
- ⬜ 让 AI 结果可复制、保存为批注、重新生成和追问。
- ⬜ 优化章节切分、长上下文压缩和引用原文定位。
- ⬜ 后续加入整本书问答和语义搜索。

验收标准：

- EPUB、MOBI、AZW3 和 PDF 均可稳定执行适用的 AI 操作。
- 网络失败不会影响本地阅读，也不会丢失当前上下文。

## 阶段 5：工程架构迁移

状态：🟡 进行中，60%。

已完成：

- ✅ BookRepository、ProgressService、ReaderAdapter 和 AI 模块边界建立。
- ✅ 无 DOM 核心逻辑和共享类型迁移到 TypeScript。
- ✅ Vitest、Vue 3、Pinia 和 WXT 已加入项目。
- ✅ WXT 入口、Vue 组件外壳和 Pinia 运行时状态已实现。
- ✅ PDF.js 和 Foliate.js 资源可以进入 WXT 构建产物。

未完成或未验收：

- 🟡 当前根目录稳定版本仍运行原生 JavaScript 阅读器。
- 🟡 Vue 外壳仍通过桥接调用旧阅读核心，并非完整 Vue 化。
- 🟡 .output/chrome-mv3 自动化测试通过，但用户实际使用用存在 bug。
- ⬜ 找到并修复 WXT 版与根目录版的行为差异。
- ⬜ 在 WXT 版达到功能、数据和体验完全等价后再停用根目录入口。

验收标准：

- WXT 版在用户真实 Edge 配置中连续使用并通过所有格式验收。
- 根目录版书库可安全迁移，功能和数据均无回退。
- 完成后删除重复入口和不再需要的桥接代码。
