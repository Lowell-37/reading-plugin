# 商店发布资料

适用于 Edge Add-ons 与 Chrome Web Store 的根目录稳定版 `静读 · 本地电子书阅读器`。提交前以 `manifest.json` 的版本、名称和实际功能为准。

## 基础信息

- 名称：静读 · 本地电子书阅读器
- 简短说明：在浏览器中离线阅读 PDF、EPUB、MOBI 与 AZW3 电子书。
- 详细说明：

  静读是一款本地优先的浏览器阅读扩展。它可以在浏览器中打开 PDF、EPUB、MOBI 和 AZW3 文件，提供目录导航、阅读进度恢复、主题和排版调整、连续滚动、全文搜索、高亮、批注与本地书库备份。

  书籍、封面、阅读进度和批注均保存在当前浏览器的本地存储中。扩展不会建立账号、不会提供云同步，也不会把书籍内容上传到开发者服务器。

  当前版本的 AI 阅读助手入口已关闭，不会发送书籍内容或发起 AI 请求。

## 权限说明

| 权限 | 用途 |
| --- | --- |
| `storage` | 保存本地阅读设置；书籍及批注保存在扩展的 IndexedDB。 |
| 可选 `http://*/*`、`https://*/*` 主机访问 | 为保留的、默认关闭的 AI 兼容接口预留。当前版本不请求也不使用该权限。 |
