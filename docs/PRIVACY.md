# 静读隐私政策

最后更新：2026-08-13

静读是一款本地优先的浏览器电子书阅读扩展。

## 我们处理的数据

扩展在当前浏览器的本地扩展存储中保存你主动打开或创建的数据，包括：书籍文件与封面、阅读进度、书签、高亮、批注、书库备份文件中的内容，以及阅读排版设置。

这些数据用于显示书架、恢复阅读位置、展示批注和执行你主动选择的本地备份/恢复操作。

## 数据传输

当前稳定版本不向开发者服务器上传书籍、批注、阅读进度或个人信息；扩展不提供账号系统、分析追踪或云同步。

AI 阅读助手的界面和触发入口当前已关闭，因此不会发送书籍内容或发起 AI 请求。若未来重新启用该功能，只有在你主动触发某项 AI 操作时，扩展才会向你自行配置的兼容 API 地址发送所选文本或当前章节所需内容；该变化会在发布说明和本政策中明确更新。

## 可选网站权限

扩展 manifest 中保留了 HTTP/HTTPS 可选主机访问能力，以支持未来由用户主动配置的 AI 兼容 API。当前版本不请求、不使用该权限，也不会因此访问网站内容。

## 数据控制与删除

你可以在书架中删除书籍，或在浏览器扩展管理页面移除扩展，以删除该浏览器配置中的扩展本地数据。建议在删除前使用“备份书库”导出 `.quietreader` 备份文件。

## 联系方式

发布到商店前，此处必须替换为开发者支持邮箱或隐私政策联系页面。
