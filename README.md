# 静读

一个本地优先的 Edge / Chrome 阅读扩展。目前优先支持：

- PDF：基于 Mozilla PDF.js，按需渲染页面与可选择文本层，支持缩放、页码跳转、书签、搜索、高亮、批注和页码进度恢复。
- EPUB：目录、封面、分页/滚动、主题与排版、全文搜索、高亮与批注、CFI 阅读位置；滚动模式按需加载相邻章节，章节结尾和下一章开头可以同时显示在同一滚动视口中；远离当前位置的章节会保留高度后释放 iframe，滚回时自动重新载入。
- MOBI / AZW3：目录、分页/滚动、主题与排版、搜索、高亮、批注和阅读位置；滚动模式支持跨章节连续文档流，不支持带 DRM 的 Kindle 文件。

书籍原文件、封面和阅读进度保存在浏览器的 IndexedDB 中，不会上传到服务器。数据库当前为 schema v2，升级步骤在单个 versionchange 事务中执行；迁移失败时浏览器会原子回滚到旧版本，不留下半迁移数据。

损坏、截断、受密码或 DRM 保护以及不支持的文件会显示持久错误页，可返回书架或重新选择文件；解析失败的新文件不会残留在书架中。

## 整书搜索

- EPUB、MOBI 和 AZW3 在当前阅读会话中按需建立章节文本缓存；同一本书后续查询不重复解析已加载章节，关闭书籍即释放缓存，不写入 IndexedDB。
- 新查询会立即取消仍在运行的旧查询；已缓存章节和当前章节优先扫描，结果列表始终按阅读顺序稳定排列。
- EPUB、MOBI、AZW3 和 PDF 共用中英文句子级上下文，点击结果可跳转到对应 CFI 或 PDF 页码。
- 搜索会统计全部匹配数量，但页面最多渲染前 300 条结果，避免超长列表阻塞阅读界面。

## 构建并加载

1. 安装依赖：`npm install`
2. 打开 Edge 的 `edge://extensions` 或 Chrome 的 `chrome://extensions`
3. 开启“开发人员模式”
4. 选择“加载解压缩的扩展”，指向项目根目录 `D:\projects\reading-plugin`
5. 点击工具栏中的“静读”图标

当前开发、日常使用和自动化验收均以项目根目录版本为准；`.output/chrome-mv3` / WXT 迁移暂不进入当前执行序列。扩展升级继续使用原来的 IndexedDB 数据库与对象仓库，不会主动清除已保存书籍和阅读进度。

根目录稳定版的打包、校验、升级与回滚步骤见 [`docs/RELEASE.md`](docs/RELEASE.md)。

Manifest 使用固定公钥，使项目移动或重新加载后仍保持相同扩展 ID 和浏览器存储来源。引入固定公钥之前安装的开发版本属于不同来源，需要重新导入一次书籍。

## 书库备份与恢复

书架首页提供“备份书库”和“恢复备份”。备份文件扩展名为 `.quietreader`，包含书籍原文件、封面、阅读进度、高亮、批注和非敏感设置；恢复前会校验备份格式版本、数据库 schema 兼容性和每个二进制文件的 SHA-256。

为避免泄露，AI API 密钥不会写入备份。恢复采用合并方式：相同书籍记录更新，其他现有书籍保留。

## 高亮与批注

在 PDF、EPUB、MOBI 和 AZW3 正文中选择文字后，可以创建高亮或带备注的批注。工具面板支持：

- 编辑批注内容和标签，并在重新打开书籍后恢复。
- EPUB/MOBI/AZW3 同时保存 CFI 与文本引文锚点；字号、行距、栏宽、分页/滚动切换及 CFI 失效后可按原文恢复并回写位置。
- PDF 同时保存页码、文本引文与相对矩形；缩放、页面重渲染和重启后会从当前文本层重新计算高亮位置。
- 向内容轻微变化的新版本书籍导入 JSON 时，只在原位置附近执行受限恢复；低置信度或并列候选保留批注并显示“需要重新定位”，不会静默高亮错误文本。
- 按有批注、仅高亮、PDF、电子书、关键词和标签筛选。
- 按最近修改、最早创建或阅读位置排序。
- 全选当前筛选结果并批量删除，删除前统一确认。
- 将当前书籍的全部高亮与批注导出为 Markdown 或版本化 JSON；导出包含书籍信息、位置、原文、备注、标签和记录时间。
- 导入版本化 JSON；导入前校验格式、版本和书籍，按批注 ID 合并，更新时间较新的记录覆盖，旧记录跳过。

## AI 阅读助手（已暂停）

AI 实现和本地配置代码仍保留，但当前稳定版已关闭界面入口和选区触发，避免任何 AI 请求。后续恢复时会重新启用入口；以下能力是已保留的实现范围：

- 划词 AI：解释、翻译、简化表达、分析术语和补充背景。
- 章节助手：章节摘要、核心观点、人物和事件、时间线、重要概念。
- EPUB、MOBI、AZW3 会读取当前 Foliate section；PDF 当前分析所在页及相邻页。
- 使用 OpenAI 兼容的 `/chat/completions` 接口，支持流式输出和停止生成。

恢复入口后，在“搜索与批注”面板中填写接口地址、模型名称和 API 密钥。扩展默认不会发送图书内容；只有点击某个 AI 功能时，才会请求对应接口权限并发送选中文字或当前章节。API 密钥保存在当前浏览器的扩展数据中，不会写入项目文件。公共或多人使用的设备不建议保存个人密钥。

总体产品与工程路线图见 [`docs/ROADMAP.md`](docs/ROADMAP.md)。
架构迁移细节见 [`docs/MIGRATION.md`](docs/MIGRATION.md)。
## 开发检查

```bash
npm run check
npm test
```

当前日常加载与测试均使用项目根目录版本。WXT 仍保留在代码中，但暂不作为稳定运行入口。

真实扩展端到端测试：

```bash
npm run test:e2e
```

该命令会构建共享核心、准备测试书，然后加载项目根目录扩展，使用本机 Microsoft Edge 验证多格式阅读、连续滚动、会话级整书搜索、异常文件、批注编辑与导出、备份恢复和数据库升级。测试书籍不会提交到 Git。

## 当前边界

- PDF 保持原版页面布局，不提供文字重排；扫描版 PDF 没有原生文本层，需要后续加入 OCR 才能搜索和选择。
- 高亮与批注保存在当前浏览器的本地数据库中，可导出 Markdown/JSON，也可从版本化 JSON 恢复；暂未提供跨设备同步。
- DRM 加密的 EPUB、MOBI、AZW3 无法读取。
